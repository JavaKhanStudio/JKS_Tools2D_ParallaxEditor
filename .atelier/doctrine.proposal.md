# Parallax Editor: Doctrine

> **PROPOSED** by the Doctrine upkeep (r35) on 2026-10-09. It binds nothing until Simon
> approves it on the board's Doctrine page. Simon accepted these six of seven candidates
> on 9 Oct; he rejected "When a change shows the moment it is made, an author tries more".

**D1. This is a library and a tool, and its only goal is to help make parallax and understand them, for both humans and AI.**
Simon's own line from the library board (parallax r62): the editor is the tool in it.

**D2. What the author sees in the editor is what the game will draw.**

**D3. Work done once by the author is better than work done every frame by every game.**

**D4. People and agents use the editor alike: neither is a second-class user.**

**D5. A page belongs to no engine: it is made once and read by every game, whatever it runs on.**
A setting only one engine can draw is an exception the editor is open about (the engine marks under a layer).

**D6. The 2019 editor is where we started, not something to preserve: what does not serve today is rewritten.**
The 2019 sample files in `editor/Files` are not part of this: they are the library's proof that format 1 loads.
